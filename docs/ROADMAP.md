# Roadmap Awal

Roadmap ini adalah urutan kerja yang disarankan. Item dapat disesuaikan saat informasi bisnis tersedia; setiap perubahan besar dicatat di [`../CHANGELOG.md`](../CHANGELOG.md).

## 1. Lengkapi materi bisnis

- [ ] Konfirmasi layanan yang ditawarkan.
- [ ] Tentukan model harga/paket atau proses penawaran.
- [ ] Siapkan profil singkat AJIEEB dan proses kerja.
- [ ] Kumpulkan portofolio yang boleh dipublikasikan atau rencanakan demo berlabel.
- [ ] Tentukan nomor WhatsApp dan jam respons.

## 2. Rancang konten dan tampilan

- [x] Susun draf teks per bagian dengan bahasa yang mudah dipahami pemilik UMKM.
- [x] Tentukan navigasi dan ajakan konsultasi utama.
- [x] Buat rancangan warna, tipografi, aset, dan tata letak responsif awal.
- [ ] Buat/konfigurasi akun Tawk.to sebelum live chat diaktifkan.
- [ ] Tampilkan Google Maps hanya pada website klien bila lokasi publik diberikan; AJIEEB belum menetapkan lokasi kantor untuk peta sendiri.

## 3. Bangun situs

- [x] Buat struktur HTML semantik awal.
- [x] Buat stylesheet responsif dan interaksi JavaScript seperlunya.
- [x] Tambahkan judul dan deskripsi unik, canonical, metadata Open Graph, `sitemap.xml`, dan `robots.txt` untuk SEO AJIEEB.
- [ ] Tambahkan favicon bila aset tersedia.
- [ ] Pastikan tombol WhatsApp memakai tautan dan nomor yang benar.
- [ ] Jangan aktifkan formulir tanpa mekanisme penerimaan pesan.

## 4. Publikasikan

- [ ] Pastikan nama domain dan dukungan konfigurasi tersedia.
- [ ] Unggah/deploy kode melalui alur GitHub dan InfinityFree yang dipilih.
- [ ] Atur Cloudflare sesuai dukungan domain, DNS, dan SSL.
- [ ] Periksa situs di perangkat dan browser umum.
- [ ] Pastikan domain final menggantikan URL rencana `ajieeb.gt.tc` jika berubah dan HTTPS aktif.
- [ ] Daftarkan dan verifikasi situs AJIEEB di Google Search Console.
- [ ] Kirim `https://ajieeb.gt.tc/sitemap.xml` di Search Console setelah domain tayang.
- [ ] Pantau pengindeksan dan perbaiki masalah yang dilaporkan Search Console.

## Catatan

Roadmap tidak menjanjikan fitur atau tanggal rilis. Tandai item selesai hanya setelah benar-benar tersedia dan dicatat dalam changelog.
